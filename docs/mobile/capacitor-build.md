# Capacitor Build

`winu-starter` portal нь web build болон Capacitor static export-ийг нэг
codebase-оос гаргана.

## Scripts

Portal дотроос ажиллуулна:

```bash
cd portal
pnpm build:cap:android:dev:packaged
```

Available scripts:

```text
build:cap:android              production remote webview URL
build:cap:android:packaged     production bundled web assets
build:cap:android:dev          staging remote webview URL
build:cap:android:dev:packaged staging bundled web assets
build:cap:ios                  production remote webview URL
build:cap:ios:packaged         production bundled web assets
build:cap:ios:dev              staging remote webview URL
build:cap:ios:dev:packaged     staging bundled web assets
sync:cap:android:local         sync native shell to local dev server
sync:cap:ios:local             sync native shell to local dev server
build:android-debug            remote Android sync + debug APK
build:android-debug:packaged   packaged Android sync + debug APK
build:androidrelease           remote Android sync + release AAB
build:androidrelease:packaged  packaged Android sync + release AAB
```

## Behavior

`scripts/build-capacitor.js` does this:

1. Ensure the native platform folder exists with `cap add <platform>`.
2. Clean stale `.next`, `out`, and platform web assets.
3. Run `next build` with `CAPACITOR_BUILD=true`.
4. Run `cap sync <platform>`.
5. For `packaged` mode, assert generated Capacitor config has no `server.url`.

The generated `android/` and `ios/` folders are intentionally ignored by git in
this starter. They can be regenerated by the build script.

## Environment Defaults

```text
production API: https://api.winu.mn/api/v1
staging API:    https://dev-api.winu.mn/api/v1
local API:      http://localhost:4000/api/v1
production web: https://portal.winu.mn
staging web:    https://dev-portal.winu.mn
local web:      http://localhost:3000
```

Override remote native URL with:

```bash
CAPACITOR_SERVER_URL="https://example.mn" pnpm build:cap:android:dev
```
